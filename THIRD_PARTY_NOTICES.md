# Third-party components

## 3D Card Effect

The project archive uses a 3D Card Effect adapted from Aceternity UI by Manu Arora (MIT):
- https://ui.aceternity.com/components/3d-card-effect
- https://ui.aceternity.com/registry/3d-card.json

Adaptations include CSS classes, reduced-motion support and pointer detection.
